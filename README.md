# 🐾 PetJoy - Pet Care, Adoption & E-Commerce Web Application

PetJoy is a full-stack web application built using **ASP.NET Core MVC**, **Entity Framework Core**, and **Microsoft SQL Server**. It provides an end-to-end platform combining everyday pet shopping, localized pet care and illness resources, formal adoption request workflows, and secure administrative dashboards with role-based access control.

---

## 🌟 Key Features

### 🛍️ Storefront & Customer Portal
- **Product Catalog:** Browse food, care products, accessories, and pet supplies with dynamic filtering by pet type, category, and brand.
- **Shopping & Checkout:** Interactive persistent shopping cart, order management, and secure checkout pipeline.
- **Flexible Checkout:** Supports Cash on Delivery (COD) and simulated credit card transactions via Stripe test mode, complete with automated order confirmation emails.
- **Adoption Module:** Browse adoptable animals and submit formal, detailed adoption application forms with status tracking.
- **Pet Care & Wellness Center:** Informational hub providing guidance on common animal illnesses, care routines, and direct referrals to Jordanian veterinary clinics.

### 🛡️ Administrative Dashboard
- **Inventory Control:** Complete CRUD management for products, stock levels, and store categories, and brands.
- **Adoption & Order Processing:** Review, approve, or reject adoption applications and manage customer orders (marking them as received or cancelled) with automated status update emails.
- **System Analytics:** Database-driven charts and statistical summaries offering high-level visibility into store performance, revenue, sales metrics, and regional adoption data.

### 🔐 Security & Access Control
- **Role-Based Authorization:** Strict access control ensuring non-administrative users cannot access internal operational routes or dashboards.
