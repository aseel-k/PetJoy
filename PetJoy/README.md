# 🐾 Petjoy - Veterinary Management & E-Commerce Web Application

Petjoy is a full-stack ASP.NET Core MVC application designed to manage veterinary services, adoption workflows, and online pet product sales.

---

## 🌟 Features Overview

### 🛍️ Storefront & Customer Experience
- Browse veterinary products and care services with category filtering.
- Interactive shopping cart, pet adoption requests, and checkout flow.

### 🛡️ Administrative Dashboard
- **Inventory & Product Control:** Manage product listings, categories, and stock.
- **Adoption & Order Management:** Process incoming adoption requests and order statuses.
- **System Analytics:** Track store performance and client engagement.

---

## 🛠️ Tech Stack & Architecture

- **Backend:** C#, ASP.NET Core MVC, Entity Framework Core
- **Database:** Microsoft SQL Server (SSMS 22)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Architecture:** MVC Pattern, Repository Pattern, Role-Based Authorization
